## 들어가기

07장에서 서보를 식별할 때 우리는 먼저 **모양**을 정했습니다. "서보는 1차+지연이다"라고 가정하고, 데이터로는 숫자 세 개($K$, $\tau$, $T_d$)만 맞췄습니다. 03장의 $K_b/s^2$도 뉴턴 법칙으로 모양을 먼저 유도했습니다.

그런데 모양을 모른다면 어떨까요? 서보에 마찰이 있고, 빔이 조금 휘고, 공이 미끄러지는데 그 식을 다 쓰기는 어렵습니다.

오늘의 질문: **"식을 모를 때, 데이터만으로 모델을 배울 수 있을까? 그렇게 배운 모델은 물리 모델만큼 믿을 만한가?"**

이 장은 AI 파트(16–20장)의 출발점입니다. 여기서 배우는 **신경망, 손실, 경사하강법, 과적합**은 17–19장에서 제어기를 학습할 때 그대로 다시 씁니다. AI를 처음 접한다고 가정하고 천천히 갑니다. 처음 보는 용어는 장 끝의 **용어 정리**에 모아 두었습니다.

## 1. 모델은 함수다

볼앤빔 모델이 하는 일을 한 줄로 쓰면 "지금 상태와 서보 명령을 넣으면, 다음 순간의 상태를 내놓는 것"입니다. 즉 **입력 → 출력 함수**입니다.

$$x_{k+1} = f(x_k,\ u_k,\ u_{k-1}),\qquad x = \begin{bmatrix} y \\ \dot y \\ \theta \end{bmatrix}$$

여기서 $k$는 샘플 번호(60 ms 간격), $y$는 공 위치, $\dot y$는 공 속도, $\theta$는 서보(빔) 각도, $u$는 서보 명령각입니다. 상태 $x$는 13장 LQR에서 쓴 것과 같은 세 가지입니다.

- **물리 모델**(03·07·08장): $f$의 모양을 법칙에서 가져오고, 숫자 몇 개($K_b$, $K$, $\tau$, $T_d$)만 데이터로 맞춥니다.
- **신경망 모델**(이 장): $f$의 모양까지 데이터에서 배웁니다. 대신 맞춰야 할 숫자가 천 개가 넘습니다.

**이 시스템에서의 의미**: 물리 모델은 "공은 빔 기울기에 비례해 가속한다"는 지식을 이미 갖고 시작하고, 신경망은 그 지식 없이 데이터에서 같은 사실을 다시 찾아내야 합니다. 지식이 없는 대신, 식으로 쓰기 어려운 효과(마찰, 포화 같은 비선형)도 데이터에 있으면 배울 수 있습니다.

### 1.1 곡선 맞추기로 감 잡기

함수를 데이터로 배운다는 것은 결국 **점들을 잘 지나는 곡선을 찾는 것**입니다. 07장에서는 곡선의 모양(지수 함수)을 정해 두고 숫자만 바꿨습니다. 신경망은 작은 꺾은선 조각(뉴런)을 많이 겹쳐서 거의 어떤 모양이든 만들 수 있습니다. 이것을 **함수 근사**라고 합니다. 조각이 많을수록 더 복잡한 모양을 만들 수 있지만, 그만큼 데이터도 많이 필요합니다(5절).

## 2. 뉴런과 다층 퍼셉트론(MLP)

### 2.1 뉴런 하나

뉴런은 입력에 각각 **가중치**를 곱해 더하고, **편향**을 더한 뒤, **활성화 함수**를 통과시킵니다.

$$a = \phi(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)$$

- $w_i$ (가중치): 입력 $x_i$를 얼마나 중요하게 볼지
- $b$ (편향): 기준점 이동
- $\phi$ (활성화 함수): 꺾임을 만드는 함수. 이 교재는 `tanh`(부드럽게 −1~1로 눌러 줌)를 기본으로 씁니다. `ReLU`(음수는 0, 양수는 그대로)도 흔합니다.

**이 시스템에서의 의미**: 활성화 함수가 없다면 $a = w^T x + b$는 06장 PD 제어기 $K_p e + K_d \dot e$와 같은 **선형 합**일 뿐입니다. 선형 층을 아무리 많이 쌓아도 결국 선형 식 하나와 같습니다. 활성화 함수의 꺾임이 있어야 서보 포화나 마찰 같은 비선형을 표현할 수 있습니다.

### 2.2 층을 쌓으면

뉴런 여러 개를 나란히 놓은 것을 **층**, 층을 여러 개 이어 붙인 것을 **다층 퍼셉트론(MLP)** 이라고 합니다. 입력층과 출력층 사이의 층은 밖에서 직접 보이지 않으므로 **은닉층**이라고 부릅니다.

## 3. 손실: "얼마나 틀렸나"를 숫자 하나로

학습하려면 먼저 "지금 모델이 얼마나 틀렸는지"를 숫자 하나로 정해야 합니다. 이것이 **손실(loss)** 입니다. 이 교재는 **평균제곱오차(MSE)** 를 씁니다.

$$L(w) = \frac{1}{N}\sum_{k=1}^{N}\left\lVert \hat{\Delta x}_k(w) - \Delta x_k \right\rVert^2,\qquad \Delta x_k = x_{k+1} - x_k$$

신경망이 다음 상태 자체가 아니라 **변화량** $\Delta x$를 예측하게 한 것은 일부러입니다. 60 ms 동안 상태는 조금만 바뀌므로, "얼마나 바뀌나"를 배우는 편이 쉽습니다.

**이 시스템에서의 의미**: 제곱 때문에 MSE는 **크게 틀린 몇 개를 특히 싫어합니다**. 1 mm 틀리면 1, 10 mm 틀리면 100을 더합니다. 그래서 초음파 센서가 가끔 튀는 값(02장 이상값)을 데이터에서 빼지 않으면, 신경망은 그 튀는 값을 맞추려고 무리합니다. 학습 전에 데이터를 점검하는 이유입니다(09장).

07장의 적합도와 비교하면, 07장은 숫자 3개를 바꿔 가며 오차를 줄였고, 신경망은 숫자 1347개를 바꿔 가며 같은 일을 합니다.

## 4. 경사하강법과 역전파: 안개 낀 산 내려가기

### 4.1 경사하강법

파라미터 1347개를 어떻게 바꿔야 손실이 줄어들까요? 비유로 시작합니다.

> 안개 낀 산에서 가장 낮은 골짜기를 찾는다. 멀리는 안 보이지만 발밑의 기울기는 느낄 수 있다. 그래서 **가장 가파르게 내려가는 방향으로 한 걸음** 가고, 다시 기울기를 느끼고, 또 한 걸음 간다.

산의 높이가 손실 $L$, 위치가 파라미터 $w$입니다. 발밑의 기울기는 **그래디언트** $\nabla L$이고, 한 걸음은

$$w \leftarrow w - \eta\,\nabla L(w)$$

입니다. $\eta$는 **학습률**(보폭)입니다. 실제로는 데이터 전체가 아니라 64개씩 묶음(미니배치)으로 기울기를 어림해 걸음을 자주 옮기고, 보폭을 방향마다 알아서 조절하는 **Adam**이라는 변형을 씁니다. 원리는 같습니다.

![두 파라미터 w1, w2 평면 위의 손실 등고선. 같은 출발점에서 학습률이 작으면 아주 조금씩 내려가고, 적당하면 골짜기 바닥에 도착하며, 너무 크면 골짜기 양쪽 벽을 넘나들며 튀어 나간다](assets/16-nn-model-id/gd-landscape.svg "그림 2. 학습률에 따른 경사하강법의 세 가지 모습(개념도).")

:::predict p2
학습률을 10배로 키우면 학습은 10배 빨리 끝날까요? 그림 2를 보기 전에 예측해 보세요.

**이 시스템에서의 의미**: 학습률은 06장의 게인과 닮았습니다. 게인을 키우면 빨라지다가 어느 순간 진동·발산하듯이, 학습률도 너무 크면 손실이 줄지 않고 튑니다. 손실이 2차 함수 골짜기라면 경사하강법은 **이산시간 피드백 루프와 똑같은 식**이 되어, "학습률 × 골짜기의 휘어진 정도 < 2"일 때만 수렴합니다(아래 접힌 상자).

:::details 1차원에서 해 보기: 학습률의 안정 조건
손실이 $L(w) = \tfrac{1}{2} c\,w^2$ (골짜기 휘어짐 $c$ > 0, 바닥 $w$ = 0)라고 합시다. 기울기는 $L'(w) = c\,w$이므로 한 걸음은

$$w_{k+1} = w_k - \eta c\, w_k = (1 - \eta c)\,w_k$$

입니다. 이것은 극점이 $1 - \eta c$인 1차 이산시간 시스템입니다(13장 이산화와 같은 꼴). $|1 - \eta c| < 1$, 즉 $0 < \eta c < 2$이면 바닥으로 수렴하고, $\eta c > 2$이면 매 걸음 반대편으로 더 멀리 튀어 발산합니다. $\eta c = 1$이면 한 걸음에 바닥에 도착합니다. 실제 신경망의 손실은 방향마다 휘어짐이 달라서, 가장 가파르게 휜 방향이 학습률의 상한을 정합니다.
:::

### 4.2 역전파: 책임 나누기

그래디언트 $\nabla L$은 "가중치 하나를 조금 바꾸면 손실이 얼마나 바뀌나"를 1347개 모두에 대해 모은 것입니다. 하나씩 조금씩 바꿔 보며 재면 너무 느리므로 **역전파**를 씁니다.

직관은 **책임 나누기**입니다. 출력에서 오차가 났으면, 그 오차에 각 뉴런이 얼마나 기여했는지를 출력 쪽에서 입력 쪽으로 **거꾸로** 나눠 줍니다. 출력에 큰 가중치로 연결된 뉴런이 더 큰 책임을 받습니다. 수학적으로는 미분의 연쇄법칙을 층마다 반복하는 것입니다.

:::details 뉴런 하나에서 연쇄법칙 보기
$\hat y = w_2\,\tanh(w_1 x)$, $L = (\hat y - y)^2$라고 하면, $h = \tanh(w_1 x)$로 두고

$$\frac{\partial L}{\partial w_2} = 2(\hat y - y)\cdot h,\qquad \frac{\partial L}{\partial w_1} = \underbrace{2(\hat y - y)}_{\text{출력 오차}}\cdot \underbrace{w_2}_{\text{뒤쪽 가중치}}\cdot \underbrace{(1 - h^2)}_{\tanh\text{ 기울기}}\cdot x$$

$w_1$의 책임은 "출력 오차 × 뒤쪽 가중치 × 활성화 기울기 × 입력"입니다. 층이 더 있으면 이 곱이 층마다 하나씩 길어집니다. 앞에서 계산한 곱을 재사용하므로, 파라미터가 수천 개여도 기울기 전체를 한 번에 효율적으로 구합니다.
:::

역전파를 손으로 계산할 일은 없습니다(앱이 합니다). 기억할 것은 두 가지입니다. (1) 학습은 "손실을 줄이는 방향으로 숫자들을 조금씩 옮기는 반복"이다. (2) 그 방향을 효율적으로 구하는 방법이 역전파다.

## 5. 학습과 검증, 그리고 과적합

### 5.1 왜 데이터를 나누나

시험 문제를 미리 보고 외운 학생은 그 시험에서는 만점이지만 실력은 알 수 없습니다. 신경망도 같습니다. 그래서 데이터를 둘로 나눕니다.

| 데이터 | 쓰임 | 비유 |
|---|---|---|
| 학습 데이터 (기본 80%) | 가중치를 바꾸는 데 쓴다 | 연습 문제 |
| 검증 데이터 (기본 20%) | 가중치를 바꾸지 않고 성능을 재기만 한다 | 처음 보는 시험 문제 |

**이 시스템에서의 의미**: 볼앤빔 데이터는 시간 순서가 있습니다. 이웃한 두 샘플(60 ms 차이)은 거의 같아서, 하나는 학습에 다른 하나는 검증에 들어가면 "답을 미리 본" 것과 비슷해집니다. 그래서 이 장은 한 단계 검증 손실만 믿지 않고, 6절에서 **학습에 쓰지 않은 연속 궤적**으로 다단계 예측을 따로 시험합니다. 10장에서 같은 조건을 반복해 평가한 것과 같은 정신입니다.

### 5.2 과적합

모델이 너무 유연하거나 데이터가 너무 적으면, 신경망은 **규칙** 대신 **잡음까지 외웁니다**. 이것이 **과적합**입니다.

![가로축은 학습 반복 횟수(에포크), 세로축은 손실(로그 눈금). 학습 손실은 계속 내려가지만 검증 손실은 처음에 함께 내려가다가 어느 지점부터 다시 올라간다. 검증 손실이 가장 낮은 지점에 조기 종료 표시가 있다](assets/16-nn-model-id/overfit.svg "그림 3. 학습 곡선으로 과적합 진단하기(개념도). 두 곡선이 벌어지기 시작하면 외우기 시작한 것이다.")

과적합을 줄이는 방법:

| 방법 | 하는 일 |
|---|---|
| 데이터 늘리기·다양하게 | 외울 수 없게 만든다. 가장 확실한 방법 |
| 모델 줄이기 | 뉴런 수·층 수를 줄인다 |
| 조기 종료 | 검증 손실이 가장 낮을 때의 가중치를 쓴다(이 앱의 기본) |
| 가중치 감쇠(L2) | 가중치가 너무 커지지 않게 손실에 벌점을 더한다 |

### 5.3 해 보기: 과적합 만들기

아래 위젯에서 먼저 기본값(데이터 3000개, 잡음 0, 은닉 32·32)으로 학습합니다. 그다음 **데이터 150개, 측정 잡음 3 mm, 은닉 64·64**로 바꿔 다시 학습합니다. "번들 결과 불러오기"를 누르면 기본값으로 미리 학습해 둔 곡선을, "과적합 시연 불러오기"를 누르면 두 번째 조건의 곡선을 바로 볼 수 있습니다 `[시뮬레이션]`. 기본값의 "학습 시작"도 번들과 같은 곡선을 냅니다.

:::widget nn-trainer {"n_samples": 3000, "noise_mm": 0, "hidden": "32,32", "epochs": 150, "lr": 0.003, "optimizer": "adam", "activation": "tanh", "allow_edit": true}:::

기본값 곡선에서 볼 것 `[시뮬레이션]`(번들 `nn-id`):
- 두 곡선 모두 처음 50 에포크쯤까지 크게 내려가고, 그 뒤로는 거의 평평합니다. 학습 손실은 0.012~0.014 근처에 머뭅니다.
- 검증 손실은 평평한 구간에서 0.0013~0.003 사이를 오르내리고, 100 에포크에서 가장 낮습니다(0.00125). 결과 망은 이 시점의 가중치입니다(조기 종료).
- 위젯이 **"과적합 신호: … 검증 손실(10 에폭 평균)은 에폭 102 뒤로 32% 늘었습니다"**라는 노란 상자를 띄웁니다. 위젯은 "검증 손실의 10 에포크 평균이 최저점보다 30% 넘게 올랐고, 그동안 학습 손실 평균은 조금이라도 줄었다"면 이 상자를 띄웁니다. 기본값에서는 아주 작은 숫자(0.001대)가 오르내린 것이 이 규칙에 걸린 것입니다.

그러니 신호가 떴다고 바로 "과적합"이라고 결론 내리지 말고 **크기**를 비교하세요. 과적합 시연에서는 검증 손실이 최저점(8 에포크, 0.655)의 2.2배(1.43)까지 오르고, 학습 손실은 0.72 → 0.063으로 10배 넘게 줄어 두 곡선이 크게 벌어집니다. 기본값에서는 학습 손실이 거의 그대로이고, 벌어지는 모양이 없습니다. 같은 경고 문구라도 두 곡선이 보여 주는 이야기는 다릅니다. 표의 "곡선 모양" 칸에 이 차이를 적으세요.

:::details 왜 기본값에서는 검증 손실이 학습 손실보다 낮을까?
보통은 처음 보는 문제(검증)를 더 못 풀기 때문에 검증 손실이 더 큽니다. 그런데 기본값 곡선은 1 에포크부터 끝까지 **검증 손실이 학습 손실보다 낮습니다**(100 에포크: 학습 0.0123, 검증 0.00125, 약 10배 차이) `[시뮬레이션]`.

계산 방식의 차이 때문은 아닙니다. 두 손실은 에포크가 끝난 뒤 같은 가중치로 계산하고, 학습 손실에만 들어가는 벌점(L2)이나 드롭아웃도 없습니다. 원인은 **데이터 몇 개**입니다.

- 3000개 표본 중 **2개**는 공이 빔 끝 멈춤판에 부딪히는 순간입니다. 속도가 한 스텝 만에 −25, −51 mm/s에서 0으로 바뀝니다. 이런 충돌은 매끄러운 규칙이 아니어서 작은 신경망이 맞추지 못하고, 6.3절에서 비교하는 물리 모델(전달함수)에도 들어 있지 않습니다.
- 무작위로 나눌 때 이 2개가 **둘 다 학습 쪽**에 들어갔습니다. 학습 손실은 평균이라서, 이 2개의 큰 오차가 학습 손실 합계의 **92%**를 차지합니다.
- 이 2개를 빼고 다시 재면 학습 0.00097, 검증 0.00125로 보통의 순서(학습 < 검증)가 됩니다. 중앙값은 학습 0.00026, 검증 0.00024로 거의 같습니다.
- 나누는 방법(무작위 시드)을 바꾸면 순서가 뒤집힙니다. 충돌 표본 하나가 검증 쪽으로 가면 검증 손실이 학습 손실보다 훨씬 커집니다(한 예: 검증 0.047, 학습 0.003).

**이 시스템에서의 의미**: "검증 손실 < 학습 손실"은 모델이 특별히 잘 일반화한다는 뜻이 아니라, **두 집합의 구성이 다르다**는 신호입니다. 표본이 드물고 아주 큰 사건(빔 끝 충돌)이 몇 개만 있어도 평균 손실은 그 몇 개에 좌우됩니다. 그래서 이 장은 한 단계 손실 하나만 믿지 않고 6.3절의 다단계 예측을 따로 봅니다. 고치는 방법으로는 충돌 표본을 표시해 따로 다루기, 궤적 단위로 학습/검증 나누기, 평균과 함께 중앙값 보기가 있습니다. 앱의 번들은 이 현상을 그대로 볼 수 있도록 고치지 않았습니다(근거: `docs/theory/ai-control.md` §3.1).
:::

## 6. 신경망으로 서보+볼앤빔 식별하기

### 6.1 무엇을 넣고 무엇을 맞추나

입력은 $[y,\ \dot y,\ \theta,\ u_k,\ u_{k-1}]$ 다섯 개, 출력은 다음 60 ms 동안의 변화 $[\Delta y,\ \Delta\dot y,\ \Delta\theta]$ 세 개입니다. 입력은 평균 0, 표준편차 1로 크기를 맞춘 뒤 넣습니다(정규화). 위치(m)와 각도(rad)는 크기 단위가 달라서, 그대로 넣으면 큰 숫자만 중요해 보이기 때문입니다.

- 속도 $\dot y$를 넣는 이유: 이중 적분기는 위치만으로는 다음을 알 수 없습니다.
- 지난 명령 $u_{k-1}$을 넣는 이유: 07장에서 본 서보 지연 때문에 지금의 서보 움직임은 **조금 전 명령**의 결과이기도 합니다.

**이 시스템에서의 의미**: 입력 목록을 정하는 일은 신경망이 아니라 사람이 합니다. 08장에서 서보를 빼먹으면 모델이 틀렸듯이, 여기서도 $\theta$나 $u_{k-1}$을 빼면 신경망은 아무리 커도 서보 지연을 배울 수 없습니다. "모양을 모른다"고 했지만, **무엇이 원인이 될 수 있는지**에 대한 물리 지식은 여전히 필요합니다.

:::note
가상 장치에서는 $\dot y$와 $\theta$의 참값을 알 수 있어서 그대로 씁니다 `[가정]`. 실제 장치라면 $\theta$는 포텐쇼미터(07장)로, $\dot y$는 위치 차분이나 관측기(13장)로 추정해야 하고, 그 잡음이 학습을 더 어렵게 만듭니다.
:::

### 6.2 데이터는 어떻게 모으나: 폐루프 수집

03장에서 본 것처럼 볼앤빔은 개루프에서 공이 끝까지 굴러가 버립니다. 그래서 학습 데이터는 **안정화 PD를 켠 채로**, 서보 명령에 07장 PRBS 같은 무작위 섭동(최대 약 ±0.15 rad)을 더하고 설정값도 수 초마다 바꿔 가며, 공이 빔 위를 고르게 돌아다니게 하며 모읍니다(폐루프 수집). 이 PD는 데이터를 모으기 위한 보조 장치라서 가상 장치의 참 상태를 쓰고 게인도 조금 큽니다($K_p$ 1.2 rad/m, $K_d$ 1.6 rad·s/m) `[가정]`.

| 데이터 조건 | 문제 |
|---|---|
| 한 위치에 가만히 있는 데이터만 | 움직임을 배울 수 없다 |
| 같은 스텝만 반복 | 그 스텝 모양만 외운다 |
| 빔의 한쪽 구간만 | 다른 구간에서 예측이 틀린다(외삽) |
| 여러 위치·속도·각도를 고르게 | 이 장의 기본(`n_samples` 3000 ≈ 3분 분량) |

### 6.3 한 단계 예측과 다단계 예측

모델을 평가하는 방법이 두 가지입니다.

- **한 단계 예측**: 매번 **실제** 현재 상태를 넣고 60 ms 뒤 하나만 예측합니다. 쉬운 시험입니다.
- **다단계 예측(자유 실행)**: 처음 상태만 실제를 주고, 그 뒤로는 **자기 예측을 다시 입력으로** 넣어 여러 단계 앞을 예측합니다. 가상 장치나 제어기 설계에 모델을 쓰려면 이 시험을 통과해야 합니다.

:::predict p3
한 단계 예측 오차가 1 mm보다 훨씬 작은 신경망이 있습니다. 50단계(3 s) 다단계 예측에서 위치 오차는 어떻게 될까요? 서보 포함 물리 모델과 비교하면 어느 쪽이 작을까요?
:::

이중 적분기에서는 작은 속도 오차가 위치 오차로 **쌓이고**, 그 틀린 상태가 다시 입력으로 들어가므로 오차가 시간에 따라 커지기 쉽습니다. 또 자기 예측이 학습 데이터에 없던 상태(예: 더 빠른 속도)로 가면 신경망은 근거 없는 값을 냅니다. 물리 모델은 구조가 맞으면 파라미터가 조금 틀려도 모양은 유지되는 경우가 많습니다.

4. 과적합. 50 에포크 근처 가중치를 쓰거나(조기 종료), 데이터를 늘리거나, 모델을 줄이거나, 가중치 감쇠를 쓴다.
5. 60 ms 이웃 샘플은 거의 같아서, 검증 샘플의 "쌍둥이"가 학습 데이터에 들어가 있다. 처음 보는 데이터가 아니게 된다.
6. 서보의 동특성(지연·시정수). 지금 서보가 얼마나 더 움직일지는 현재 각도와 조금 전 명령에 달려 있는데, 그 정보가 입력에 없다.
7. 한 단계에서는 실제 상태가 매번 오차를 바로잡아 준다. 다단계에서는 자기 예측의 작은 속도 오차가 이중 적분기를 거쳐 위치 오차로 쌓이고, 틀린 상태가 학습 범위 밖 입력이 되어 더 틀린다. 19장의 분포 이동과 같은 구조다.

## 용어 정리

| 용어 | 뜻 (이 교재에서) |
|---|---|
| 신경망 | 가중치를 조절해 모양을 바꿀 수 있는 유연한 함수 |
| 함수 근사 | 정해진 식 대신 유연한 함수로 입력-출력 관계를 흉내 내는 것 |
| 뉴런 | 가중합 + 편향 → 활성화 함수 |
| 가중치·편향 (파라미터) | 학습으로 바뀌는 숫자들 |
| 활성화 함수 | 꺾임을 만드는 함수(tanh, ReLU). 없으면 신경망은 선형 |
| MLP (다층 퍼셉트론) | 뉴런 층을 여러 개 이은 신경망. 가운데 층이 은닉층 |
| 정규화 | 입력마다 평균 0, 표준편차 1이 되게 크기를 맞추는 것 |
| 손실 | 모델이 얼마나 틀렸는지를 나타내는 숫자 하나. 여기서는 평균제곱오차(MSE) |
| 경사하강법 | 손실이 가장 빨리 줄어드는 방향으로 파라미터를 조금씩 옮기는 반복 |
| 학습률 | 한 걸음의 크기. 너무 크면 발산 |
| 미니배치, Adam | 데이터 일부로 기울기를 어림해 자주 걷기 / 방향마다 보폭을 조절하는 경사하강법 |
| 역전파 | 출력 오차의 책임을 층마다 거꾸로 나눠 기울기를 효율적으로 구하는 방법(연쇄법칙) |
| 에포크 | 학습 데이터를 한 바퀴 다 쓰는 것 |
| 학습/검증 데이터 | 가중치를 바꾸는 데 쓰는 데이터 / 성능만 재는 데이터 |
| 과적합 | 규칙 대신 잡음까지 외워 처음 보는 데이터에서 틀리는 것 |
| 조기 종료 | 검증 손실이 가장 낮을 때의 가중치를 쓰는 것 |
| 한 단계 / 다단계 예측 | 실제 상태로 다음 하나 예측 / 자기 예측을 다시 넣어 멀리 예측 |

## 요약과 다음 챕터

- 모델은 입력 → 출력 함수다. 물리 모델은 모양을 법칙에서, 신경망은 모양까지 데이터에서 얻는다.
- 신경망 학습 = 손실을 정하고, 경사하강법으로 파라미터를 조금씩 옮기는 반복. 기울기는 역전파로 구한다.
- 검증 데이터로 과적합을 진단한다. 학습 곡선이 벌어지면 외우기 시작한 것이다.
- 다단계 예측에서는 작은 오차가 쌓인다. 데이터 범위 밖에서는 신경망을 믿지 않는다.
- 이 장의 비교는 가정 서보 가상 장치의 `[시뮬레이션]`이며, 물리 모델이 데이터를 만든 모델과 같아 유리하다.
