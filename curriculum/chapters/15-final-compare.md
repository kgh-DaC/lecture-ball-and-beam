## 들어가기

06장의 수동 PID에서 시작해 서보 식별(07), 모델 비교(08), 평가 도구(09, 10), 오토튜닝(11), 적응형 PID(12), LQR(13), 슬라이딩모드(14)까지 왔습니다. 각 챕터에서 가장 좋은 결과를 슬롯에 승격해 두었다면, 이제 그것들을 한자리에 모읍니다.

오늘의 질문: **"이 볼앤빔에는 어떤 제어기를 써야 하는가? 그리고 그 답은 무엇에 따라 달라지는가?"**

정답은 하나가 아닙니다. 이 챕터의 결과물은 "○○가 최고다"가 아니라, **조건과 근거가 붙은 권고**와 그것을 담은 보고서입니다.

## 1. 동일 조건 비교 설계

10장의 공정 비교 규칙을 다시 확인합니다. 비교 전에 표를 채우세요.

| 조건 | 값 | 모든 제어기에서 같은가? |
|---|---|---|
| 설정값 프로파일 | P1 표준 스텝 (150 → 200 mm) | |
| 각도 한계 | | |
| 샘플 주기 / 필터 α | 60 ms / 0.2 | |
| 서보 (HS-5645MG / SG90) | | |
| 공 | | |
| 반복 횟수 | 3회 이상 | |
| 출처 | `실측` / `시뮬레이션` | |

:::warning
**출처가 다른 결과를 섞어서 우열을 매기지 마세요.** 슬롯이 어떤 제어기는 `내 실측`, 어떤 제어기는 번들 `시뮬레이션`으로 채워져 있다면, 그 비교는 "실제 장치 대 모델"의 비교이지 제어기의 비교가 아닙니다. 비교 화면은 이런 경우 `조건 상이` 배지를 붙이고 우열 기호를 표시하지 않습니다. 하드웨어 없이 이 과정을 끝낸 경우에는 **시뮬레이션끼리** 비교하고, 결론에 "가정 서보 모델 기준"이라고 적으세요.
:::

추가 비교(선택): 왕복(P2: 150 ↔ 200 mm)과 원근 계단(P3: 120 → 170 → 270 → 170 mm)에서도 비교하면 운전점 변화(12장)와 반복 추종 성능을 볼 수 있습니다. 프로파일이 다르면 묶음도 다르므로 표를 따로 만듭니다.

## 4. 흔한 결론의 함정

종합 비교에서 자주 나오는 문장들입니다. 여러분의 데이터로 맞는지 확인하세요.

- **"LQR은 최적이니까 가장 좋다."** → $J$의 정의와 모델에 대해서만 최적입니다(13장). 10장 지표에서 잘 튜닝한 PID와 차이가 흩어짐보다 작을 수 있습니다.
- **"게인이 크면 빠르다."** → 지연이 있는 이 시스템에서는 게인을 키우면 위상여유가 줄어 오히려 오래 진동합니다(05, 08장).
- **"서보는 명령대로 움직인다."** → 07장에서 잰 지연과 시정수가 08장에서 위상여유를 9° 가까이 깎았습니다(가정 서보 기준).
- **"SMC는 항상 채터링한다 / 항상 강인하다."** → 경계층 안에서는 PD입니다(14장). 강인성은 $\eta$와 오차 상한의 관계로만 보장됩니다.
- **"한 번 해 봤더니 B가 좋았다."** → 반복과 평균±편차 없이는 결론이 아닙니다(10장).

## 6. 보고서

보고서는 **앱이 내보내는 데이터 ZIP**과 **여러분이 직접 정리하는 문서** 두 부분으로 이루어집니다.

`final-compare`의 **보고서 내보내기(ZIP)**에는 다음 파일만 들어 있습니다.

1. `final_compare.csv`: 비교한 항목마다 이름, 제어기, 출처(`provenance`: `real`/`simulated`), 시행 수 n, 지표별 평균·표준편차
2. `final_compare.json`: 비교에 고른 항목 목록(`refs`: 슬롯·샘플·세션 식별자)과 지표 목록, 내보낸 시각
3. (목록에서 **내 세션**을 하나 이상 골랐을 때만) `manifest.json`과 그 세션들의 원자료 `session_<id>.json`(메타)·`session_<id>.csv`. 슬롯·번들 샘플로만 비교했다면 원자료 파일은 들어가지 않고, `final_compare.json`의 식별자로 어떤 데이터인지 남습니다.

그래프 그림, 1절 조건 표, 해석은 **ZIP에 들어가지 않습니다**. 다음은 여러분이 따로 정리해 ZIP과 함께 제출합니다.

- 그래프: 위젯의 레이더·막대 그래프를 화면 캡처하거나, `final_compare.csv`로 직접 그립니다
- 조건 표(1절)와 출처 표시: 항목마다 `실측`/`시뮬레이션`과 모델·잡음 조건을 적습니다(CSV의 `provenance` 열을 옮기면 됩니다)
- 여러분의 해석: 3절 트레이드오프 표, 5절 의사결정 표, 결론 한 문단(워크시트 15에 칸이 있습니다)

결론 문단은 10장 형식을 따릅니다: 조건 → 수치(평균±편차, 시행 횟수) → 상충 → 권고. 수치 없는 문장은 결론이 아닙니다.

## 생각해 보기

채점하지 않는 질문입니다. 답을 먼저 적어 보고, 막히면 아래 실마리를 열어 보세요.

1. pid-best는 '내 실측', lqr-best는 번들 '시뮬레이션'이다. LQR의 오버슈트가 더 작게 나왔다. 올바른 결론은? (보기: LQR이 더 좋다 / 출처가 달라 제어기 비교가 아니다. 같은 출처(둘 다 실측 또는 둘 다 시뮬레이션)로 다시 비교해야 한다 / PID가 더 좋다 / 출처는 비교와 무관하다)
2. 제어기를 고를 때 성능 지표 외에 함께 볼 기준을 모두 고르라. (보기: 제어 노력(u_rms, u_tv) / 강인성(모델 오차에 대한 민감도) / 모델 의존도 / 튜닝 노력 / 제어기 이름의 유명도)
3. 레이더 차트(정규화 값, 바깥쪽이 나쁨)에서 한 제어기가 오버슈트 축은 안쪽, u_tv 축은 바깥쪽에 있다. 해석은? (보기: 모든 면에서 우수하다 / 오버슈트는 작지만 서보를 많이 떨게 한다(상충) / 데이터 오류다 / u_tv는 무시해도 된다)
4. gs-best(P3 원근 계단)와 pid-best(P1 표준 스텝)를 한 표에서 비교하면? (보기: 그대로 비교하면 된다 / 프로파일이 달라 조건 상이 — 같은 프로파일에서 다시 실행한 결과끼리 비교한다 / 정착시간만 비교할 수 있다 / P3가 더 어려우므로 gs-best에 가산점을 준다)
5. 여러분 장치(또는 가상 장치)의 결과로 '공 종류가 자주 바뀌는 상황'에 권할 제어기를 한 문단으로 쓰라. 조건, 수치, 상충, 권고를 포함하라.

:::details 생각의 실마리 (스스로 답을 적어 본 뒤 열기)
1. 시뮬레이션은 잡음·지연·마찰이 모델만큼만 들어 있다. 실측 대 시뮬레이션의 차이는 제어기 차이가 아니라 '현실 대 모델'의 차이를 섞는다.
2. 이름이나 '최적'이라는 수식어가 아니라, 같은 조건에서 측정한 근거로 판단한다.
3. 상충이다. 응용(기어 수명, 소음)에 따라 어느 쪽을 중시할지 판단해 보고서에 적는다.
4. 설정값 프로파일은 비교 묶음의 기준이다. 다른 프로파일의 지표는 같은 실험의 결과가 아니다.
5. 예: '조건 P1, 가상 장치(가정 서보), kb_scale 1.0과 1.19 각 3회. SMC(sat, Φ 0.05)는 오버슈트가 □ ± □%에서 □ ± □%로 변해 변화가 가장 작았고, 10장 PID는 □%에서 □%로 변했다. 대신 SMC의 u_tv는 PID의 약 □배였다. 공 종류가 자주 바뀌고 서보 마모가 크게 문제되지 않으면 SMC를 권한다.' 숫자는 학생 데이터로 채운다.
:::

## 정리: 이 교재에서 한 일

| 단계 | 챕터 | 배운 것 |
|---|---|---|
| 모델링 | 01–03 | 블록선도, $K_b/s^2$, 이중 적분기의 의미 |
| 고전 설계 | 04–05 | 근궤적·주파수 응답으로 PD/PID, 지연과 위상여유 |
| 실험과 불일치 | 06 | 예측보다 진동하는 실측, 가설 세우기 |
| 모델 보완 | 07–08 | 서보 식별, 전체 전달함수, 재설계 |
| 평가 | 09–10 | 샘플·점수·승격, 반복 검증과 공정 비교 |
| 고급 제어 | 11–14 | 오토튜닝, 적응, LQR, 슬라이딩모드 |
| 종합 | 15 | 같은 조건 비교, 트레이드오프, 근거 있는 권고 |

제어기 설계는 "정답 게인"을 외우는 일이 아니라, **모델을 세우고, 예측하고, 재고, 차이의 원인을 찾아 고치는** 반복입니다. 여러분의 시도 이력 표가 그 기록입니다.

최고 결과를 승격해 두었다면, 교수자가 그것을 다음 학기 교재의 샘플로 넣을 수 있습니다. 여러분의 실측이 다음 학생들의 출발점이 됩니다.
