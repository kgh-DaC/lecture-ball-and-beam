# 아두이노 기초와 사용법

:::part theory

:::note
**이 장의 목표**
- 아두이노 보드·브레드보드·전원·시리얼 연결을 이해하고, IDE로 스케치를 컴파일·업로드·시리얼 모니터로 확인한다
- 디지털 출력, PWM과 H-bridge, 부저, 초음파 거리 측정, 적외선 센서 입력, 블루투스(SoftwareSerial)를 작은 예제로 직접 해 본다
- 각 모듈의 배선도·AI에게 줄 프롬프트·검증된 예제·체크리스트·확인 문제를 순서대로 따라 한다
- SMARS 모듈에서 배운 기능이 볼앤빔의 어느 부품·핀으로 이어지는지 짝짓는다
:::

## 들어가기

이 장은 **SMARS 로봇 수업 교재의 M1~M6 모듈**을 그대로 씁니다. 같은 M1~M6이 [SMARS 수업 페이지](https://kgh-dac.github.io/lecture-SMARS/lesson.html#m1)에도 있으며, 이 부분(M1~M6)은 두 곳이 같은 파일을 동기화해서 씁니다(한쪽을 고치면 다른 쪽에도 반영됩니다).

각 모듈 카드는 같은 틀로 되어 있습니다.

| 칸 | 내용 |
|---|---|
| ① 원리 | 그림·애니메이션으로 보는 동작 원리 (M1은 6단계: 보드 → 신호선·전원선 → 전원 공급 → 시리얼 → 브레드보드 → IDE·CH340·보레이트) |
| ② 배선도 | 그 모듈에서 쓰는 핀만 그린 배선 |
| ③ 프롬프트 | AI(바이브코딩)에게 줄 요청문 — 핀 번호가 자동으로 들어감 |
| ④ 예제 | 컴파일이 확인된 예제 스케치(복사 버튼) |
| ⑤ 체크리스트 | 해 봤는지 표시(이 브라우저에 저장) |
| ⑥ 확인 문제 | 3~5문항 |

| 모듈 | 주제 | 볼앤빔에서 다시 쓰는 곳 |
|---|---|---|
| M1 | 아두이노·브레드보드·바이브코딩 입문 | 보드·USB 시리얼·IDE 업로드 전부 |
| M2 | DC모터·H-bridge·PWM | PWM 개념 → 서보 펄스(아래 3절) |
| M3 | 부저 | 디지털 출력 |
| M4 | 초음파 | **HC-SR04 공 위치 측정** (같은 센서) |
| M5 | 적외선 라인센서 (선택) | 디지털 입력 |
| M6 | 블루투스 | 시리얼 통신·SoftwareSerial |

:::warning
SMARS 모듈의 **핀 번호는 SMARS 로봇(모터 쉴드) 기준**입니다. 볼앤빔 장치의 핀은 다릅니다(아래 3절 표, [02장](#/ch/02-hardware)). SMARS 예제를 볼앤빔 보드에 그대로 올리지 마세요.
:::

## 2. 볼앤빔으로 이어가기

SMARS에서 익힌 기능이 볼앤빔에서는 이렇게 쓰입니다.

![가운데 Arduino Nano. 왼쪽: USB(D0·D1) 시리얼 통신은 PC 웹 앱, D13 디지털 출력은 내장 LED, A0 아날로그 입력은 서보 포텐쇼미터. 오른쪽: D6·D7 디지털 입출력과 시간 재기는 HC-SR04 초음파 센서, D9 타이머·PWM은 서보모터, 인터럽트는 개념만 다룬다](assets/a1-arduino-basics/board-map.svg "그림 1. 볼앤빔 장치의 기능 ↔ 부품 ↔ 핀. 실제 배선(실드 헤더, 서보 전원)은 02장 6절.")

| 기능 | SMARS (M1~M6) | 볼앤빔 |
|---|---|---|
| 보드 | Arduino UNO + 모터 쉴드 | Arduino Nano 호환(CH340) + I/O 실드 — 칩은 같은 ATmega328P |
| 초음파 HC-SR04 | Trig D7, Echo D8 (M4) | **Trig D6, Echo D7** — 공까지 거리 |
| PWM 출력 | 모터 속도 D10·D11 (M2) | **서보 D9** — 펄스폭으로 빔 각도 |
| 아날로그 입력 | — | **A0** — 서보 포텐쇼미터(개조) 각도 |
| USB 시리얼 | 57600 baud | **115200 baud** — 웹 앱과 측정값·명령 교환 |
| 블루투스 | HC-05, SoftwareSerial A1·A0 (M6) | 쓰지 않음 |

### 2.1 PWM에서 서보 펄스로

M2에서 PWM은 "켜진 시간의 비율(듀티비)로 모터의 평균 전압을 바꾸는 것"이었습니다. 서보는 같은 PWM 핀을 쓰지만 읽는 방식이 다릅니다. **20 ms마다 오는 펄스의 폭(약 0.5~2.4 ms, 1.5 ms ≈ 가운데)** 이 곧 각도 명령입니다. 아래 위젯에서 펄스폭을 바꾸며 서보 각을 확인해 보세요.

:::widget pwm-demo {"servo_model": "current", "pulse_us": 1500, "show_period": true}:::

### 2.2 초음파 거리 측정은 그대로

M4의 초음파 원리(Trig 10 µs → Echo HIGH 시간 → 거리 = 시간 × 음속 ÷ 2)는 볼앤빔에서도 같습니다. 볼앤빔 펌웨어는 손계산 340 m/s 대신 343 m/s를 쓰고, 60 ms마다 측정해 PC로 보냅니다(02장).

## 3. 실습

1. 위 1절의 M1~M6 카드를 순서대로 진행합니다(M5는 선택). 각 카드의 ⑤ 체크리스트를 채우고 ⑥ 확인 문제를 풉니다.
2. 보드가 SMARS 로봇이 아니라 볼앤빔 장치뿐이라면 M1(LED·시리얼)과 M4(초음파)만 해 보고, M4 예제의 핀을 **Trig D6, Echo D7**, 보레이트를 **115200**으로 바꿔 올려 봅니다(바이브코딩 프롬프트의 [핀] 칸을 고치면 됩니다).
3. 끝나면 워크시트 a1의 "볼앤빔 핀 짝짓기" 표를 채웁니다.

:::warning
SMARS 모터 실습(M2)은 바퀴를 띄운 채로 합니다. 배선을 바꿀 때는 USB와 배터리를 모두 뺍니다. 볼앤빔 서보는 보드 5V가 아니라 별도 5.0 V 전원으로 구동합니다(02장).
:::

## 요약과 다음 챕터

- M1~M6에서 보드·전원·시리얼·IDE, PWM·H-bridge, 부저, 초음파, 라인센서, 블루투스를 예제로 익혔다.
- 볼앤빔은 같은 ATmega328P 칩에서 **초음파(D6·D7), 서보 PWM(D9), 포텐쇼미터 ADC(A0), USB 시리얼(115200)** 을 쓴다.
- PWM은 모터에서는 듀티비(평균 전압), 서보에서는 펄스폭(각도 명령)으로 읽힌다.

**다음 챕터(02 하드웨어 구성)**: 볼앤빔 장치의 배선, 서보 별도 전원, 펌웨어 업로드, 포텐쇼미터 개조, 센서·서보 한계 측정을 다룹니다.
