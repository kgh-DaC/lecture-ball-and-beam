# 서보 포함 모델과 이전 모델 비교

:::part theory

:::note
**이 장의 목표**
- 서보 모델을 포함한 전체 전달함수를 만들고 극점·위상여유 변화를 설명한다
- 같은 PID에 대해 두 모델 예측과 실측을 겹쳐 적합도·지표 차이로 정량 비교한다

## 들어가기

06장에서 실측이 서보 무시 모델의 예측보다 더 진동한다는 것을 보았고, 07장에서 서보가 명령각을 얼마나 늦게 따라가는지 재서 $G_{servo}(s)$를 얻었습니다. 이제 둘을 합칩니다.

오늘의 질문: **"서보를 넣은 모델은 06장의 실측을 얼마나 더 잘 설명하는가? 그 모델로 다시 설계하면 실측이 좋아지는가?"**

이 챕터의 결과물은 (1) 두 모델 중 어느 쪽이 실측에 더 가까운지 보여 주는 **숫자**(적합도, 오버슈트 차이)와 (2) 서보 포함 모델로 다시 설계한 PID와 그 실험 결과입니다.

## 1. 전체 전달함수

03장의 기구부 모델과 07장의 서보 모델을 직렬로 연결합니다.

$$P(s) = G_{servo}(s)\cdot\frac{K_b}{s^2} = \frac{K\,K_b\,e^{-T_d s}}{s^2(\tau s + 1)}$$

**이 시스템에서의 의미**: 명령각을 바꾸면 서보가 $T_d$만큼 기다렸다가 시정수 $\tau$로 따라가고, 그 실제 각도가 공을 가속합니다. 이중 적분기 앞에 "늦은 1차 시스템"이 하나 더 붙은 것입니다.

![명령각이 순수 지연과 1차 서보 K/(tau s + 1)을 거쳐 실제 각 theta가 되고 빔·공 K_b/s^2가 공 위치 y를 만드는 블록선도. 아래 실수축에 개루프 극점 0, 0과 가정 서보 극점 −16.7을 표시했다](assets/08-model-compare/full-plant.svg "그림 1. 서보 포함 전체 전달함수: 멀리 있는 서보 극점(−1/τ)도 교차주파수 근처의 위상을 깎는다 [가정].")

이 챕터의 숫자는 07장 번들 기본값인 **가정 서보** $K$ = 1, $\tau$ = 0.06 s, $T_d$ = 0.02 s로 계산했습니다 [가정]. 07장에서 여러분이 `result.json`을 저장했다면 아래 위젯은 **여러분의 식별 결과**로 다시 계산하므로 숫자가 달라집니다. 달라지는 것이 정상입니다.

:::details 속도 한계(fo_slew)는 전달함수에 어떻게 들어가나
07장의 `fo_slew` 모델에는 최대 속도 $v_{max}$가 있습니다. 속도 한계는 비선형이므로 전달함수에는 넣을 수 없고, 앱의 근궤적·보드 계산은 $v_{max}$를 빼고 $K e^{-T_d s}/(\tau s+1)$만 씁니다(소신호 근사). 반면 가상 장치와 시뮬레이션(`simulate`)은 $v_{max}$를 그대로 적용합니다. 그래서 큰 스텝에서는 선형 해석(근궤적, 보드)과 시뮬레이션 결과가 조금 다를 수 있습니다.
:::

## 2. 극점과 위상: 멀리 있는 극점이 왜 중요한가

| 모델 | 개루프 극점 | 지연 |
|---|---|---|
| 서보 무시 (`ball`) | 0, 0 | 없음 |
| 서보 포함 (`ball+servo`) | 0, 0, $-1/\tau$ = −16.7 rad/s [가정] | $T_d$ = 0.02 s [가정] |

−16.7 rad/s는 05장의 이득교차주파수(약 1~2 rad/s)보다 열 배 가까이 멉니다. 그래서 "무시해도 되겠지"라고 생각하기 쉽습니다. 그런데 교차주파수 근처에서 이 극점과 지연이 깎는 위상은

$$\Delta\phi_{servo}(\omega) = \tan^{-1}(\tau\omega) + \omega T_d \ \ (\text{rad})$$

이고, $\omega$ = 2 rad/s에서 약 9.1°입니다 [가정]. 센서 필터 때문에 위상여유가 이미 20°대로 줄어든 설계라면 9°는 결코 작은 몫이 아닙니다.

:::predict p1
06장 안전 기본값 PD($K_p$ = 1.0, $K_d$ = 1.5, 측정값 미분, 센서 필터 α = 0.2)의 위상여유는 서보 무시 모델에서 약 33°입니다. 서보를 넣으면 몇 도가 될까요?
:::

### 3.1 "더 잘 맞는다"를 숫자로

눈으로 보는 것만으로는 부족합니다. 두 가지 숫자로 말하세요.

1. **적합도**(07장과 같은 정의): $\text{fit} = 100\left(1 - \dfrac{\lVert y - \hat y\rVert}{\lVert y - \bar y\rVert}\right)$%. 여기서 $y$는 (c)의 위치(실측이어야 모델 검증이 됩니다), $\hat y$는 모델 예측입니다.
2. **지표 차이**: 오버슈트, 정착시간의 (예측 − (c)).

| 항목 | (a) 서보 무시 | (b) 서보 포함 | (c) `pid-best` (출처: ____) |
|---|---|---|---|
| 오버슈트 (%) | | | |
| 정착시간 (s) | | | |
| (c)에 대한 적합도 (%) | | | – |

:::warning
`pid-best` 슬롯의 배지를 먼저 확인하세요. 배지가 `시뮬레이션`이면(번들 `sim-pid-p1`이나 가상 장치 세션) 그것은 실측이 아니므로, 위 비교는 "모델 대 모델" 비교일 뿐 **모델 검증이 아닙니다**. 모델이 실제를 얼마나 잘 설명하는지는 `실측` 또는 `내 실측` 배지가 붙은 데이터로만 말할 수 있습니다. 장치가 없다면 이 절의 결론을 "실측 데이터가 생기면 확인할 가설"로 적어 두세요.
:::

## 4. 실패 사례: 잘못 고른 서보 모델

07장에서 30° 큰 스텝으로 식별한 모델은 속도 한계 때문에 $\tau$가 크게 추정됩니다. 그 모델을 쓰면 예측이 실제보다 **더** 진동하는 쪽으로 틀립니다. 반대로 서보를 무시하면 덜 진동하는 쪽으로 틀립니다.

:::predict p2
07장에서 30° 스텝으로 얻은 $\tau$(작은 스텝보다 큼)를 서보 모델로 쓰면, 예측 오버슈트는 실측보다 클까요, 작을까요?
:::

`model-compare` 위젯에서 서보 모델을 바꿔 가며 확인해 보세요. 실측과 가장 잘 맞는 모델은 보통 **제어할 때 실제로 쓰는 진폭(몇 도 이내)에서 식별한 모델**입니다. 모델은 "참"이 아니라 "이 용도에 쓸 만한가"로 고릅니다.

그 밖에도 서보 포함 모델로 다 설명되지 않는 차이가 남을 수 있습니다: $K_b$ 오차(03장의 R 25/26 mm 문제), 빔 수평 오차, 레일 마찰, 초음파 반사 위치. 남은 차이를 이 목록에서 골라 근거와 함께 적는 것도 이 챕터의 과제입니다.

## 요약과 다음 챕터

- 전체 전달함수는 $P(s) = G_{servo}(s)K_b/s^2$. 서보 극점은 멀리 있어도 교차주파수 근처에서 위상을 깎는다.
- 게인이 큰(빠른) 설계일수록 서보를 무시한 대가가 크다.
- "모델이 더 잘 맞는다"는 적합도와 지표 차이로, **실측 데이터에 대해서만** 말할 수 있다.
- 서보 포함 모델로 재설계하면 여유를 미리 확보할 수 있지만, 속도와 잡음 사이의 트레이드오프는 남는다.
