# 나이키스트·보드로 PID 설계

:::part theory

:::note
**이 장의 목표**
- 볼앤빔 개루프의 보드·나이키스트 선도를 읽고 이득·위상·지연 여유를 구한다
- 센서 필터와 샘플링 지연이 위상여유를 깎는 정도를 계산한다
- 위상여유 목표(≥ 35°, D 필터 N = 8·센서 필터·샘플링 지연 포함)로 PD 게인을 재조정하고, D 필터가 위상여유를 제한하는 이유를 설명한다

## 들어가기

04장에서 근궤적으로 PD를 설계했고, 연속 모델에서는 사양을 거의 만족했습니다. 그런데 가상 장치(60 ms 샘플링, 센서 필터 포함)에서 실행하면 같은 게인인데도 오버슈트가 커졌습니다. 근궤적은 다항식의 근을 다루므로 **시간 지연** 같은 요소를 그대로 넣기 어렵습니다.

오늘의 질문: **"센서 필터와 샘플링이 만드는 '늦음'은 제어를 얼마나 망가뜨리고, 얼마나 늦어도 버틸 수 있는가?"**

주파수 응답(보드 선도, 나이키스트 선도)은 지연을 정확하게 다룰 수 있고, "얼마나 여유가 있는가"를 각도(위상여유)와 시간(지연여유)으로 바로 알려 줍니다 [슬라이드 30].

## 1. 주파수 응답: 빔을 사인파로 흔들면

안정한 선형 시스템에 사인파 $\sin\omega t$를 넣으면 출력도 같은 주파수의 사인파이고, **크기 비** $|G(j\omega)|$와 **위상차** $\angle G(j\omega)$만 달라집니다.

볼앤빔 기구부 $P(j\omega) = K_b/(j\omega)^2 = -K_b/\omega^2$:
- 크기: $K_b/\omega^2$ → 주파수가 10배가 되면 1/100(−40 dB/decade)
- 위상: 항상 **−180°**

**이 시스템에서의 의미**: 빔을 천천히 흔들면 공이 크게 움직이고, 빨리 흔들면 거의 움직이지 않습니다. 그리고 공은 언제나 빔과 **정반대 박자**로 움직입니다(빔이 오른쪽으로 가장 기울었을 때 공은 왼쪽 끝에 있음). 위상 −180°가 바로 "되먹임이 양의 되먹임으로 뒤집히기 직전"이라는 뜻이라서, 볼앤빔은 제어하기 까다롭습니다.

## 2. 보드 선도

개루프 $L(j\omega) = C(j\omega)P(j\omega)$의 크기(dB)와 위상(°)을 로그 주파수축에 그린 것입니다. PD $C = K_p + K_d s$는 모서리 주파수 $\omega = K_p/K_d$ 위에서 위상을 최대 +90°까지 **끌어올립니다**. 이 덕분에 위상이 −180°보다 위로 올라와 안정해집니다.

:::note
위젯의 PD는 앱의 실제 제어기와 같이 **D 필터**가 들어 있습니다: $C(s) = K_p + \dfrac{K_d s}{T_f s + 1}$, $T_f = K_d/(N K_p)$, `n_filt` $N$ = 8. 슬라이드 48 PD에서는 $T_f$ = 2.0684/(8 × 2.3884) ≈ 0.108 s입니다. 이 필터도 작은 지연이라서, 위젯이 보여 주는 위상여유는 약 **51.5°**로 D 필터가 없는 순수 PD의 이상값(약 60.8°)보다 9°쯤 작습니다 [시뮬레이션: `analysis.margins`]. 이 챕터의 숫자는 위젯 설정(N = 8)을 기준으로 쓰고, 순수 PD 값은 비교로만 적습니다.
:::

### 2.1 이득여유와 위상여유

- **이득교차주파수** $\omega_{gc}$: $|L| = 1$ (0 dB)인 주파수
- **위상여유 PM** $= 180° + \angle L(j\omega_{gc})$: 위상이 −180°까지 얼마나 남았나
- **위상교차주파수** $\omega_{pc}$: $\angle L = -180°$인 주파수
- **이득여유 GM** $= -20\log_{10}|L(j\omega_{pc})|$: 이득을 몇 배 더 키울 수 있나

![보드 선도. 위는 개루프 크기(dB), 아래는 위상(도). 크기가 0 dB를 지나는 이득교차주파수 약 1.91 rad/s에서 위상을 읽고, −180도까지 남은 약 34도가 위상여유이다. 슬라이드 48 PD에 센서 필터 alpha = 0.2를 넣은 경우](assets/05-nyquist/bode-pm.svg "그림 1. 보드 선도에서 위상여유 읽기: |L| = 0 dB인 ω_gc에서 −180°까지 남은 각도 [시뮬레이션, D 필터 없는 순수 PD].")

**이 시스템에서의 의미**: 이상적인 PD + 이중 적분기는 위상이 −180°에 닿지 않으므로 이득여유가 무한대입니다. 게인을 아무리 키워도 불안정해지지 않는다는 뜻인데, 그것은 **지연이 전혀 없다는 가정** 때문입니다. 현실에서 위험한 것은 이득이 아니라 위상(늦음)입니다.

위상여유와 감쇠비 사이에는 대략 $\zeta \approx PM/100$ (PM < 70°)의 관계가 있습니다. PM이 줄면 오버슈트가 커집니다.

## 3. 나이키스트 판별법

$L(j\omega)$를 복소평면에 하나의 곡선으로 그리면, 곡선이 **−1 점을 몇 번 감싸는가**로 폐루프 안정성을 판별합니다.

$$Z = N + P$$

- $P$: 개루프 우반면 극점 수 (볼앤빔은 0. 원점 극점은 작은 반원으로 우회합니다)
- $N$: −1 점을 시계 방향으로 감싼 횟수
- $Z$: 폐루프 우반면 극점 수. $Z = 0$이어야 안정

**이 시스템에서의 의미**: −1 점은 "되먹임 신호가 원래 신호와 같은 크기로 정반대 박자"인 곳, 즉 시스템이 스스로 진동을 유지하는 조건입니다. 곡선이 −1에서 얼마나 떨어져 있는가가 여유입니다. 위상여유는 단위원 위에서 −1까지의 각도 거리입니다.

## 4. 지연은 위상을 갉아먹는다

순수 시간 지연 $e^{-sT}$는 크기를 바꾸지 않고 위상만 $-\omega T$ (rad) 깎습니다. 위상여유가 PM(rad)이면 지연이 $T = PM/\omega_{gc}$가 될 때 곡선이 −1을 지나므로

$$\text{지연여유} = \frac{PM\ (\text{rad})}{\omega_{gc}}$$

### 4.1 볼앤빔의 늦음은 어디서 오나

| 원인 | 크기 | 출처 |
|---|---|---|
| 센서 재귀 필터 | 1차 지연, $T_f = T_s(1-\alpha)/\alpha$ → α = 0.2에서 0.24 s | 02장 |
| 샘플링(ZOH) | 대략 $T_s/2$ = 0.03 s | 60 ms 주기 |
| 통신·브라우저 처리 | 대략 5~10 ms | 아키텍처 예산 [가정] |
| 서보가 명령각을 따라가는 시간 | **아직 모름** | 07장에서 측정 |

:::predict p1
슬라이드 48 PD(2.3884, 2.0684)의 위상여유는 지연이 없을 때 위젯 설정(D 필터 N = 8)으로 약 51.5°입니다. 센서 필터(α = 0.2)를 넣으면 위상여유는 몇 도쯤으로 줄어들까요?
:::

오른쪽 순수 PD 열과 비교해 보세요. 모든 줄에서 D 필터가 위상여유를 약 9~10° 더 깎습니다. **늦음은 더해집니다**: 센서 필터, 샘플링, D 필터가 각각은 작아 보여도 교차주파수 근처에서 합치면 여유의 대부분을 먹습니다.

## 7. 실습: 여유를 남긴 재설계 (가상 장치)

1. 센서 필터 α = 0.2와 지연 0.03 s를 포함했을 때(보드 위젯 `fd-sensor`, D 필터 N = 8) **PM ≥ 35°**가 되도록 $K_p$, $K_d$를 조정합니다. 출발점인 슬라이드 48 PD는 21.5°입니다. 힌트: 이득을 낮추거나($\omega_{gc}$를 낮춤) $K_d/K_p$ 비율을 조정해 교차주파수 근처 위상을 끌어올립니다.
2. 조정한 게인과 슬라이드 48 PD를 가상 장치에서 표준 스텝으로 각각 실행하고 오버슈트를 비교합니다.
3. **도전(실패 사례)**: 목표를 PM ≥ 45°로 올려 보세요. 게인을 어디까지 바꿔야 하나요?

:::predict p3
같은 조건(α = 0.2 + 0.03 s)에서 D 필터가 없는 순수 PD라면 PM 45°는 쉽게 얻을 수 있습니다(예: $K_p$ = 0.5, $K_d$ = 1.5에서 약 56°). 그런데 위젯 설정(N = 8)에서는 $K_d/K_p$를 키워도 위상여유가 잘 오르지 않습니다. 왜일까요?
:::

:::details 도전 과제 풀이 (예측을 쓴 뒤 열어 보기)
D 필터의 시정수는 $T_f = K_d/(N K_p)$입니다. 위상을 끌어올리려고 $K_d/K_p$를 키우면 $T_f$도 같은 비율로 커져, D 항이 주는 위상 앞섬을 D 필터가 다시 늦춥니다. 계산해 보면 N = 8에서 PM 45°는 $K_p$ ≈ 0.1, $K_d$ ≈ 0.5 근처(교차주파수 약 0.5 rad/s, 매우 느린 응답)에서만 겨우 얻어집니다 [시뮬레이션: `analysis.margins`]. 더 큰 여유가 필요하면 `n_filt`를 키우거나(D 필터 지연 감소, 대신 잡음 증가) 센서 필터 α를 키우는(필터 지연 감소, 대신 잡음 증가) 수밖에 없습니다. 08장에서 서보까지 넣고 이 문제를 다시 만납니다.

## 생각해 보기

채점하지 않는 질문입니다. 답을 먼저 적어 보고, 막히면 아래 실마리를 열어 보세요.

1. P(s) = 0.8709/s²의 ω = 1 rad/s에서 크기(dB)는?
2. 위상여유 60°, 이득교차주파수 2 rad/s인 루프의 지연여유(s)는?
3. 순수 지연 0.03 s가 ω = 2 rad/s에서 만드는 위상 지연(°)은?
4. 센서 필터(T_f = 0.24 s)가 ω = 1.91 rad/s에서 만드는 위상 지연(°)은?
5. 지연이 전혀 없는 이상적 PD + 이중 적분기 루프의 이득여유는? (보기: 0 dB / 약 6 dB / 무한대 / 음수)
6. 슬라이드 49에서 필터 sensitivity를 0.1로 낮추자 곡선은 부드러워졌지만 정착이 늦어졌다. 위상여유로 설명하라.

:::details 생각의 실마리 (스스로 답을 적어 본 뒤 열기)
1. |P(j1)| = 0.8709 → 20·log10(0.8709) ≈ −1.20 dB. 위상은 모든 주파수에서 −180°다.
2. 지연여유 = PM(rad)/ωgc = 1.0472/2 ≈ 0.524 s.
3. ωT = 0.06 rad ≈ 3.44°. 샘플링(ZOH) 지연 자체는 크지 않다. 센서 필터가 훨씬 크다(q4).
4. atan(0.24 × 1.91) = atan(0.458) ≈ 24.6°. 이 지연이 D 필터 없는 순수 PD 기준으로 슬라이드 48 PD의 위상여유를 60.8°에서 34.2°로 줄인다(교차주파수도 2.06 → 1.91 rad/s로 낮아짐). 위젯 설정(D 필터 N = 8)에서는 교차주파수가 약 2.0 rad/s라 51.5°에서 24.9°로 준다.
5. 위상이 −180° + atan(Kd ω/Kp)로 항상 −180°보다 위에 있어 위상교차주파수가 없다. 지연이나 필터가 들어가야 유한한 이득여유가 생긴다.
6. sensitivity(α)를 낮추면 필터 시정수 T_f = T_s(1−α)/α가 0.24 s에서 0.54 s로 커져 교차주파수 근처에서 위상 지연이 커진다. 위상여유가 크게 줄어(슬라이드 48 PD, 위젯 설정 N = 8 기준 약 25°→6°; 순수 PD 기준 34°→13°) 감쇠가 작아지고 진동이 오래 남아 정착이 늦어진다.
:::

## 요약과 다음 챕터

- 볼앤빔 기구부는 위상이 항상 −180°. PD가 교차주파수 근처의 위상을 끌어올려 안정하게 만든다.
- 나이키스트: $Z = N + P$, −1 점과의 거리가 여유다.
- 지연여유 = PM/$\omega_{gc}$. 센서 필터(α = 0.2) 하나로 슬라이드 48 PD의 위상여유가 51.5°에서 24.9°로, 샘플링 지연 0.03 s까지 넣으면 21.5°로 준다(위젯 설정 D 필터 N = 8; 순수 PD라면 60.8° → 34.2°) [시뮬레이션].
- D 필터도 늦음이다. N = 8에서는 PD만으로 PM 45°를 얻기 어렵다.
- 게인을 키우면 빨라지지만 지연여유가 줄어든다.
