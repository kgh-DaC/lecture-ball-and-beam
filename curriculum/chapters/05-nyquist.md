# 나이키스트·보드로 PID 설계

:::part theory

:::note

- 볼앤빔 개루프의 보드·나이키스트 선도를 읽고 이득·위상·지연 여유를 구한다

## 들어가기

04장에서 근궤적으로 PD를 설계했고, 연속 모델에서는 사양을 거의 만족했습니다. 그런데 가상 장치(60 ms 샘플링, 센서 필터 포함)에서 실행하면 같은 게인인데도 오버슈트가 커졌습니다(슬라이드 48 PD, 미분을 측정값에: 4.3% → 약 25%). 근궤적은 다항식의 근을 다루므로 **시간 지연** 같은 요소를 그대로 넣기 어렵습니다.

오늘의 질문: **"센서 필터와 샘플링이 만드는 '늦음'은 제어를 얼마나 망가뜨리고, 얼마나 늦어도 버틸 수 있는가?"**

주파수 응답(보드 선도, 나이키스트 선도)은 지연을 정확하게 다룰 수 있고, "얼마나 여유가 있는가"를 각도(위상여유)와 시간(지연여유)으로 바로 알려 줍니다 [슬라이드 30].

## 1. 주파수 응답: 빔을 사인파로 흔들면

안정한 선형 시스템에 사인파 $\sin\omega t$를 넣으면 출력도 같은 주파수의 사인파이고, **크기 비** $|G(j\omega)|$와 **위상차** $\angle G(j\omega)$만 달라집니다.

볼앤빔 기구부에 $s = j\omega$를 넣으면 $P(j\omega) = K_b/(j\omega)^2 = -K_b/\omega^2$, 곧 **음의 실수**입니다.

| | 값 | 뜻 |
|---|---|---|
| 크기 $\lvert P(j\omega)\rvert$ | $K_b/\omega^2$ | 주파수가 10배가 되면 1/100 (−40 dB/decade) |
| 위상 $\angle P(j\omega)$ | 항상 **−180°** | 음의 실수이므로 주파수와 상관없이 부호만 반대 |

![빔 각을 사인파로 흔들 때 공 위치는 같은 주파수의 사인파이지만 부호가 반대다. 빔이 +쪽으로 가장 기운 순간 공은 −쪽 끝에 있다](assets/05-nyquist/antiphase.svg "그림 1. 빔과 공은 정반대 박자: 기구부의 위상은 모든 주파수에서 −180°다.")

**이 시스템에서의 의미**: 빔을 천천히 흔들면 공이 크게 움직이고, 빨리 흔들면 거의 움직이지 않습니다. 그리고 공은 언제나 빔과 **정반대 박자**로 움직입니다(빔이 오른쪽으로 가장 기울었을 때 공은 왼쪽 끝에 있음). 위상 −180°가 바로 "되먹임이 양의 되먹임으로 뒤집히기 직전"이라는 뜻이라서, 볼앤빔은 제어하기 까다롭습니다.

## 2. 보드 선도

개루프 $L(j\omega) = C(j\omega)P(j\omega)$의 크기(dB)와 위상(°)을 로그 주파수축에 그린 것입니다. PD $C(j\omega) = K_p + jK_d\omega$의 위상은

$$\angle C(j\omega) = \tan^{-1}\frac{K_d\,\omega}{K_p}$$

로, 모서리 주파수 $\omega = K_p/K_d$에서 +45°, 그 위에서 최대 +90°까지 위상을 **끌어올립니다**. 이 덕분에 개루프 위상이 −180°보다 위로 올라와 안정해집니다. 04장에서 "영점이 궤적을 왼쪽으로 끌어당긴다"고 본 것을 주파수 영역에서는 "영점이 위상을 끌어올린다"고 읽습니다.

위젯의 PD는 앱의 실제 제어기와 같이 **D 필터**가 들어 있습니다: $C(s) = K_p + \dfrac{K_d s}{T_f s + 1}$, $T_f = K_d/(N K_p)$, `n_filt` $N$ = 8. 슬라이드 48 PD에서는 $T_f$ = 2.0684/(8 × 2.3884) ≈ 0.108 s입니다. 이 필터도 작은 지연이라서, 위젯이 보여 주는 위상여유는 약 **51.7°**로 D 필터가 없는 순수 PD의 이상값(약 61.4°)보다 10°쯤 작습니다 [시뮬레이션: `analysis.margins`]. 이 챕터의 숫자는 위젯과 같은 조건($K_b$ = 0.8993, N = 8)을 기준으로 쓰고, 순수 PD 값은 비교로만 적습니다.

위상여유와 감쇠비 사이에는 대략 $\zeta \approx PM/100$ (PM < 70°)의 관계가 있습니다. PM이 줄면 오버슈트가 커집니다.

## 3. 나이키스트 판별법

$L(j\omega)$를 복소평면에 하나의 곡선으로 그리면, 곡선이 **−1 점을 몇 번 감싸는가**로 폐루프 안정성을 판별합니다.

$$Z = N + P$$

| 기호 | 뜻 | 볼앤빔에서 |
|---|---|---|
| $P$ | 개루프 우반면 극점 수 | 0 (원점의 극점 둘은 작은 반원으로 우회) |
| $N$ | 곡선이 −1 점을 시계 방향으로 감싼 횟수 | 지연이 지연여유보다 작으면 0 |
| $Z$ | 폐루프 우반면 극점 수. **0이어야 안정** | $N$ = 0이면 0 → 안정 |

**이 시스템에서의 의미**: −1 점은 "되먹임 신호가 원래 신호와 같은 크기로 정반대 박자"인 곳, 즉 시스템이 스스로 진동을 유지하는 조건입니다. 곡선이 −1에서 얼마나 떨어져 있는가가 여유입니다. 위상여유는 단위원 위에서 −1까지의 각도 거리입니다.

![복소평면에 개루프 L(jω) 곡선(파란 실선), 단위원, −1 점을 그렸다. 곡선이 단위원과 만나는 점에서 −1까지의 각도(초록 호)가 위상여유이다. 지연 0.2초를 더한 곡선(주황 점선)은 위상이 돌아가 −1에 더 가까워진다](assets/05-nyquist/nyquist-pm.svg "그림 3. 나이키스트 선도의 위상여유와 지연: 지연은 크기를 그대로 두고 곡선을 −1 쪽으로 돌린다(51.7° → 지연 0.2 s에서 26.1°).")

## 4. 지연은 위상을 갉아먹는다

순수 시간 지연 $e^{-sT}$는 크기를 바꾸지 않고 위상만 $-\omega T$ (rad) 깎습니다. 위상여유가 PM(rad)이면 지연이 $T = PM/\omega_{gc}$가 될 때 곡선이 −1을 지나므로

$$\text{지연여유} = \frac{PM\ (\text{rad})}{\omega_{gc}}$$

예: 위 위젯(`fd`)은 PM 51.7° = 0.903 rad, $\omega_{gc}$ = 2.24 rad/s이므로 지연여유 = 0.903/2.24 ≈ 0.40 s입니다. 그림 3의 지연 0.2 s는 그 절반이라 위상여유도 절반쯤(0.2 × 2.24 rad ≈ 25.6°)이 깎였습니다.

### 4.2 위상 예산: 누가 얼마나 깎나

위상여유는 교차주파수에서 각 요소의 위상을 **더한 것**입니다. 강조한 줄($\omega_{gc}$ = 2.05 rad/s)을 요소별로 나누면 다음과 같습니다.

| 요소 | 식 | $\omega$ = 2.05 rad/s에서 |
|---|---|---|
| 기구부 $K_b/s^2$ | −180° | 기준선 |
| PD가 올림(D 필터의 영점 포함) | $+\tan^{-1}\!\big(\omega\,(K_d/K_p + T_{f,D})\big)$ | +63.4° |
| D 필터 ($T_{f,D}$ = 0.108 s) | $-\tan^{-1}(T_{f,D}\,\omega)$ | −12.5° |
| 센서 필터 ($T_f$ = 0.24 s) | $-\tan^{-1}(T_f\,\omega)$ | −26.2° |
| 샘플링 지연 (0.03 s) | $-\omega T$ (rad) | −3.5° |
| **남은 위상여유** | 합 | **21.2°** |

![교차주파수 2.05 rad/s에서의 위상 예산 폭포 그림. PD가 63.4도를 올리고 D 필터가 12.5도, 센서 필터가 26.2도, 샘플링 지연이 3.5도를 깎아 21.2도가 남는다](assets/05-nyquist/phase-budget.svg "그림 4. 위상 예산: PD가 끌어올린 각도를 늦음 세 가지가 나눠 먹는다. 가장 큰 몫은 센서 필터다.")

**이 표가 의미하는 것**: 여유를 늘리고 싶으면 가장 큰 몫부터 봅니다. 센서 필터(α)가 26°, D 필터(N)가 12°, 샘플링이 3.5°이므로 손댈 순서도 그 순서입니다. 다만 필터를 약하게 하면 잡음이 커집니다(02장 5절). 07장에서 서보의 늦음이 이 표에 한 줄 더 들어갑니다.

## 6. 근궤적 설계와 비교

같은 지연을 근궤적에서 보려면 지연을 유리함수(Padé 근사)로 바꿔야 합니다. 1차 Padé 근사는

$$e^{-sT} \approx \frac{1 - sT/2}{1 + sT/2}$$

로, 크기는 1이고 위상만 늦는 유리함수입니다. 분자의 영점 $s = +2/T$가 **오른쪽 반평면**에 있다는 점이 중요합니다. 아래 근궤적은 이 근사로 지연 0.27 s(지연여유 0.40 s의 약 2/3)를 넣은 것입니다. 오른쪽 반평면의 영점이 가지를 오른쪽으로 끌어당겨, 주극점이 지연 없을 때의 $-1.20 \pm 1.21j$에서 $-0.61 \pm 2.39j$($\zeta$ ≈ 0.25)로 옮겨 간 모습을 보세요 [시뮬레이션: `analysis.closedLoop`].

:::note
근사는 근사입니다. 1차 Padé로 계산하면 이 루프는 지연 0.42 s에서도 아직 안정하고 0.45 s에서야 불안정해집니다. 정확한 지연여유 0.40 s보다 **낙관적**입니다. 안정 한계를 따질 때는 주파수 응답 쪽 값을 믿으세요.
:::

|---|---|---|

| 지연 | 근사 필요(Padé) | 정확 |

## 7. 실습: 여유를 남긴 재설계 (가상 장치)

1. 센서 필터 α = 0.2와 지연 0.03 s를 포함했을 때(보드 위젯 `fd-sensor`, D 필터 N = 8) **PM ≥ 35°**가 되도록 $K_p$, $K_d$를 조정합니다. 출발점인 슬라이드 48 PD는 21.2°입니다. 힌트: 이득을 낮추거나($\omega_{gc}$를 낮춤) $K_d/K_p$ 비율을 조정해 교차주파수 근처 위상을 끌어올립니다.
2. 조정한 게인과 슬라이드 48 PD를 가상 장치에서 표준 스텝으로 각각 실행하고 오버슈트를 비교합니다.
3. **도전(실패 사례)**: 목표를 PM ≥ 45°로 올려 보세요. 게인을 어디까지 바꿔야 하나요?

:::predict p3
같은 조건(α = 0.2 + 0.03 s)에서 D 필터가 없는 순수 PD라면 PM 45°는 쉽게 얻을 수 있습니다(예: $K_p$ = 0.5, $K_d$ = 1.5에서 약 56°). 그런데 위젯 설정(N = 8)에서는 $K_d/K_p$를 키워도 위상여유가 잘 오르지 않습니다. 왜일까요?
:::

:::details 도전 과제 풀이 (예측을 쓴 뒤 열어 보기)
D 필터의 시정수는 $T_f = K_d/(N K_p)$입니다. 위상을 끌어올리려고 $K_d/K_p$를 키우면 $T_f$도 같은 비율로 커져, D 항이 주는 위상 앞섬을 D 필터가 다시 늦춥니다. 같은 게인($K_p$ = 0.5, $K_d$ = 1.5)이 순수 PD로는 56°인데 N = 8에서는 31°입니다. 계산해 보면 N = 8에서 PM 45°는 $K_p$ ≈ 0.1, $K_d$ ≈ 0.5 근처(교차주파수 약 0.5 rad/s, 매우 느린 응답)에서만 겨우 얻어집니다 [시뮬레이션: `analysis.margins`].

| 게인 ($K_p$, $K_d$) | $\omega_{gc}$ (rad/s) | PM | 가상 장치 오버슈트 | 앱 표시(유지 8 s) | 95% 도달 |
|---|---|---|---|---|---|
| 슬라이드 48 (2.3884, 2.0684) | 2.05 | 21.2° | 약 25% | 25% | 1.2 s |
| 재설계 예 (0.5, 1.0) | 1.04 | 36.5° | 약 3% | 4% | 3.0 s |
| PM 35°를 넘는 가장 빠른 쪽 (0.55, 1.2) | 1.18 | 35.3° | 0% | 1%\* | 3.2 s |
| 도전 (0.1, 0.5) | 0.51 | 45.3° | 0% | 5%\* | 8.6 s |

\* 설정값을 넘지 않는 응답입니다. "오버슈트" 칸은 30 s 관찰한 값이고, 앱은 관찰 창의 마지막 20% 평균을 최종값으로 삼으므로(10장 2절) 8 s 창이 끝날 때 아직 올라가는 중인 응답은 0이 아닌 값이 표시됩니다. 느린 설계일수록 이 차이가 큽니다.

[시뮬레이션: PM은 `analysis.margins`(α = 0.2 + 0.03 s, N = 8), 오버슈트와 도달 시간은 `simulate`(서보 무시, 60 ms, α 0.2, 잡음 없음, 미분은 측정값에)] 더 큰 여유가 필요하면 `n_filt`를 키우거나(D 필터 지연 감소, 대신 잡음 증가) 센서 필터 α를 키우는(필터 지연 감소, 대신 잡음 증가) 수밖에 없습니다. 08장에서 서보까지 넣고 이 문제를 다시 만납니다.
:::

## 생각해 보기

채점하지 않는 질문입니다. 답을 먼저 적어 보고, 막히면 아래 실마리를 열어 보세요.

1. P(s) = 0.8993/s²의 ω = 1 rad/s에서 크기(dB)는?
2. 위상여유 60°, 이득교차주파수 2 rad/s인 루프의 지연여유(s)는?
3. 순수 지연 0.03 s가 ω = 2 rad/s에서 만드는 위상 지연(°)은?
4. 센서 필터(T_f = 0.24 s)가 ω = 1.91 rad/s에서 만드는 위상 지연(°)은?
5. 지연이 전혀 없는 이상적 PD + 이중 적분기 루프의 이득여유는? (보기: 0 dB / 약 6 dB / 무한대 / 음수)
6. 슬라이드 49에서 필터 sensitivity를 0.1로 낮추자 곡선은 부드러워졌지만 정착이 늦어졌다. 위상여유로 설명하라.

:::details 생각의 실마리 (스스로 답을 적어 본 뒤 열기)
1. |P(j1)| = 0.8993 → 20·log10(0.8993) ≈ −0.92 dB(슬라이드 값 기준 0.8709면 −1.20 dB). 위상은 모든 주파수에서 −180°다.
2. 지연여유 = PM(rad)/ωgc = 1.0472/2 ≈ 0.524 s.
3. ωT = 0.06 rad ≈ 3.44°. 샘플링(ZOH) 지연 자체는 크지 않다. 센서 필터가 훨씬 크다(q4).
4. atan(0.24 × 1.91) = atan(0.458) ≈ 24.6°. 필터를 넣은 루프의 교차주파수(순수 PD 1.96, 위젯 설정 2.05 rad/s) 근처 값이다. 이 지연이 D 필터 없는 순수 PD 기준으로 슬라이드 48 PD의 위상여유를 61.4°에서 34.3°로 줄인다(교차주파수도 2.12 → 1.96 rad/s로 낮아짐). 위젯 설정(D 필터 N = 8)에서는 51.7°에서 24.7°로 준다.
5. 위상이 −180° + atan(Kd ω/Kp)로 항상 −180°보다 위에 있어 위상교차주파수가 없다. 지연이나 필터가 들어가야 유한한 이득여유가 생긴다.
6. sensitivity(α)를 낮추면 필터 시정수 T_f = T_s(1−α)/α가 0.24 s에서 0.54 s로 커져 교차주파수 근처에서 위상 지연이 커진다. 위상여유가 크게 줄어(슬라이드 48 PD, 위젯 설정 N = 8 기준 약 25°→6°; 순수 PD 기준 34°→13°) 감쇠가 작아지고 진동이 오래 남아 정착이 늦어진다.
:::

## 요약과 다음 챕터

- 볼앤빔 기구부는 위상이 항상 −180°. PD가 교차주파수 근처의 위상을 끌어올려 안정하게 만든다.
- 나이키스트: $Z = N + P$, −1 점과의 거리가 여유다.
- 지연여유 = PM/$\omega_{gc}$. 센서 필터(α = 0.2) 하나로 슬라이드 48 PD의 위상여유가 51.7°에서 24.7°로, 샘플링 지연 0.03 s까지 넣으면 21.2°로 준다(위젯 설정 D 필터 N = 8; 순수 PD라면 61.4° → 34.3°) [시뮬레이션].
- 위상여유는 요소별 위상의 합이다(위상 예산). 교차주파수에서 센서 필터 26°, D 필터 12°, 샘플링 3.5°를 깎는다.
- D 필터도 늦음이다. N = 8에서는 PD만으로 PM 45°를 얻기 어렵다.
- 게인을 키우면 빨라지지만 지연여유가 줄어든다.
