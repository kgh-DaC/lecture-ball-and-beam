# 적응형 PID

:::part theory

:::note
**이 장의 목표**
- 오차 크기와 공의 종류(K_b)에 따라 고정 게인이 최선이 아닌 이유를 설명한다
- 게인 스케줄링의 경계 출력 튐을 계산하고 보간·bumpless 전환으로 완화한다
- MRAC(MIT 규칙)의 기준 모델·적응 이득·투영의 역할을 설명하고 고정 PID와 검증 도구로 비교한다

## 들어가기

06~11장의 PID는 게인을 한 번 정하면 실험 내내 그대로였습니다. 그런데 공이 목표에서 멀리 있을 때와 거의 도착했을 때, 같은 게인이 최선일까요? 탁구공 대신 쇠구슬을 올리면요?

오늘의 질문: **"상황이 바뀌면 게인도 바뀌어야 하는가? 바뀐다면 누가, 어떻게 바꾸는가?"**

두 가지 방법을 봅니다.
- **게인 스케줄링**: 사람이 미리 정한 규칙(오차가 크면 이 게인, 작으면 저 게인)으로 바꾼다. 슬라이드 50의 방식 [슬라이드 50].
- **모델 기준 적응 제어(MRAC)**: "원하는 응답"을 정해 두고, 실제 응답이 그것과 다르면 제어기가 스스로 게인을 고친다.

## 1. 운전점이 바뀌는 두 가지 경우

### 1.1 오차의 크기

공이 목표에서 100 mm 이상 떨어져 있을 때 큰 $K_p$를 쓰면 명령이 각도 한계에 붙고(포화), 공이 빠르게 굴러와 크게 지나칩니다. 반대로 목표 근처에서 작은 $K_p$를 쓰면 마찰을 이기지 못해 오차가 남습니다. "멀 때는 부드럽게, 가까울 때는 단단하게"가 직관입니다.

### 1.2 플랜트가 바뀜: 공의 종류

03장의 식에서 $K_b = \dfrac{m g d}{L\,(J/R^2 + m)}$입니다. 공의 관성이 $J = c\,mR^2$이면

$$K_b = \frac{g\,d}{L\,(1 + c)}$$

로 **질량과 반지름에 상관없이 공의 모양**($c$)만으로 정해집니다. 속이 빈 공($c$ = 2/3)은 $K_b$ = 0.899, 속이 찬 공($c$ = 2/5)은 $K_b$ = 1.071 m/s²/rad으로 약 **19% 큽니다**($g$ = 9.8 m/s², 슬라이드 치수 $d$ = 0.052 m, $L$ = 0.34 m로 계산). 공을 바꾸면 같은 PID라도 루프 게인이 19% 커져 교차주파수와 위상여유가 바뀝니다.

**이 시스템에서의 의미**: "무거운 공으로 바꿨다"가 아니라 "속이 찬 공으로 바꿨다"가 모델을 바꿉니다. 가상 장치에서는 `kb_scale` = 1.19로 이 상황을 흉내 냅니다.

## 3. 실패 사례: 경계에서 튀는 출력

:::predict p1
공이 목표에서 정확히 10 cm 떨어진 순간(속도 0이라고 하자) "멂" 영역에서 "가까움" 영역으로 넘어가면, P 항만으로 서보 명령은 몇 도 바뀔까요?
:::

경계에서 $K_p$가 0.66861에서 2.3884로 갑자기 바뀌므로 P 항이 $\Delta K_p \cdot e$ = (2.3884 − 0.66861) × 0.10 = 0.172 rad, 약 **9.9°** 계단처럼 뜁니다. 오차가 경계 근처에서 잡음으로 오르내리면 명령이 이 크기로 **반복해서** 튀어 서보가 덜컥거립니다.

해결책 세 가지(앱의 `blend`, `bumpless` 옵션):

| 방법 | 원리 | 대가 |
|---|---|---|
| 선형 보간 (`linear`) | 경계 ± `blend_width`/2 구간에서 게인을 직선으로 섞는다 | 중간 게인의 성능은 설계하지 않은 것 |
| 시그모이드 (`sigmoid`) | S자 곡선으로 부드럽게 섞는다 | 위와 같음 |
| bumpless 전환 | 게인이 바뀌는 순간의 출력 차이를 보정 항으로 흡수하고 0.5 s 동안 서서히 0으로 | 전환 직후 0.5 s 동안 실제 게인과 다른 출력 |

가상 장치에서 `switch` → `sigmoid` → `sigmoid` + `bumpless`를 차례로 실행하고 `u_cdeg` 그래프에서 경계 통과 순간을 비교하세요.

## 4. MRAC: 원하는 응답을 따라가도록 스스로 고친다

### 4.1 기준 모델

먼저 "이렇게 움직였으면 좋겠다"를 2차 시스템으로 정합니다(01장의 $\zeta$, $\omega_n$).

$$\ddot y_m = \omega_n^2 (r - y_m) - 2\zeta\omega_n \dot y_m$$

기본값은 $\zeta$ = 0.9, $\omega_n$ = 1.2 rad/s입니다. 서보·센서 지연이 있으므로 기준 모델을 너무 빠르게 잡으면 실제 장치가 따라갈 수 없습니다.

### 4.2 MIT 규칙

제어 법칙은 PD($u = k_p e - k_d \dot y_f$)이고, 게인을 다음처럼 계속 고칩니다.

$$\dot k_p = -\gamma\, e_m\, \frac{\partial y}{\partial k_p}, \qquad e_m = y - y_m$$

즉 "기준 모델과의 차이 $e_m$을 줄이는 방향으로, 그 게인이 $y$에 영향을 주는 정도만큼" 게인을 움직입니다(경사 하강). 앱은 여기에 두 가지 안전장치를 둡니다.

- **정규화**: 신호 크기로 나눠, 큰 스텝에서 게인이 갑자기 크게 변하지 않게 한다.
- **투영**: $k_p$, $k_d$를 정해진 범위(기본 $k_p$ 0.2~4, $k_d$ 0.5~5) 밖으로 나가지 못하게 한다.
- 그리고 **포화 중에는 적응을 멈춘다**: 명령이 한계에 붙어 있을 때는 게인을 바꿔도 응답이 달라지지 않으므로, 그때의 $e_m$으로 게인을 고치면 엉뚱한 방향으로 간다.

![모델 기준 적응 제어 구조. 목표 r이 기준 모델로 원하는 응답 y_m을 만들고, PD 제어기와 볼앤빔이 실제 출력 y를 만든다. 두 출력의 차 e_m을 적응 법칙(MIT 규칙, 정규화, 투영)이 받아 PD 게인을 조정한다](assets/12-adaptive-pid/mrac.svg "그림 2. MRAC 구조: 기준 모델과의 차이 e_m으로 PD 게인을 스스로 고친다.")

**이 시스템에서의 의미**: 속이 찬 공으로 바꿔 $K_b$가 19% 커지면 같은 $k_p$로는 응답이 기준 모델보다 빨라지고 더 지나칩니다. MRAC는 $e_m$을 보고 $k_p$를 낮추는 쪽으로 스스로 움직입니다.

:::predict p2
적응 이득 $\gamma$를 기본값 1에서 10으로 키우면 게인 시계열(`adaptation-plot`)은 어떤 모양이 될까요?
:::

### 4.3 실패 사례: 너무 빠른 적응

$\gamma$가 크면 적응이 빨라지지만, 지연과 잡음이 있는 루프에서는 게인이 진동하거나 투영 한계 사이를 오가며 응답이 오히려 나빠집니다. 적응 루프 자체가 하나의 되먹임 루프이고, 그 루프에도 안정 여유가 필요합니다. 실기에서 $\gamma$의 상한은 5입니다. 10은 가상 장치에서만 시험하세요.

채점하지 않는 질문입니다. 답을 먼저 적어 보고, 막히면 아래 실마리를 열어 보세요.

1. 슬라이드 50 게인(Kp 가까움 2.3884, 멂 0.66861)에서 오차 0.10 m, 속도 0일 때 경계를 넘는 순간 P 항 명령 변화(°)는? (소수 첫째 자리)
2. J = c·m·R²인 공에서 K_b = g·d/(L(1 + c)). 속이 찬 공(c = 2/5)의 K_b는 속이 빈 공(c = 2/3)의 몇 배인가? (소수 둘째 자리)
3. 기준 모델 ζ = 0.9, ωn = 1.2 rad/s의 극점 실수부 크기(1/s)는? (소수 둘째 자리)
4. MRAC가 명령이 포화된 동안 적응을 멈추는 이유는? (보기: 계산량을 줄이려고 / 포화 중에는 게인을 바꿔도 응답이 달라지지 않아, 그때의 오차로 게인을 고치면 잘못된 방향으로 가므로 / 포화 중에는 기준 모델이 멈추므로 / 투영 범위를 넘지 않게 하려고)
5. 게인 스케줄링에서 bumpless 전환이 하는 일은? (보기: 경계를 없앤다 / 게인이 바뀌는 순간 출력 차이를 보정 항으로 흡수해 계단을 없애고 서서히 넘긴다 / 적분을 0으로 만든다 / 경계 근처에서 제어를 멈춘다)
6. 게인 스케줄링과 MRAC 중 '공을 탁구공에서 쇠구슬로 바꾸는 상황'에 더 적합한 것은? 이유와 한계를 함께 쓰라.

:::details 생각의 실마리 (스스로 답을 적어 본 뒤 열기)
1. ΔKp·e = 1.71979 × 0.10 = 0.172 rad = 9.85°. 잡음으로 경계를 오가면 이 크기로 반복해서 튄다.
2. (1 + 2/3)/(1 + 2/5) = 1.667/1.4 = 1.190. 질량·반지름이 아니라 공의 모양이 K_b를 바꾼다.
3. s = −ζωn ± jωn√(1 − ζ²) = −1.08 ± j0.52. 실수부 크기 ζωn = 1.08이 응답이 줄어드는 빠르기다.
4. MIT 규칙은 게인이 출력에 주는 영향(감도)을 가정한다. 포화되면 그 영향이 사라지므로 오차를 게인 탓으로 돌리면 게인이 엉뚱하게 표류한다.
5. 출력 차이를 b 항으로 흡수하고 시정수 0.5 s로 감쇠시킨다. 게인 전환은 그대로이고 출력만 연속이 된다.
6. MRAC가 더 적합하다. 게인 스케줄링은 오차 크기를 기준으로 미리 정한 게인을 쓰므로 공의 종류(K_b 변화)를 모른다. MRAC는 기준 모델과의 차이로 K_b 변화의 영향을 감지해 게인을 고친다. 한계: 적응에 시간이 걸리고, γ가 크면 적응 루프가 불안정해지며, 포화·잡음이 많으면 적응이 잘못될 수 있다. 공 종류를 미리 안다면 공별 게인표(스케줄링 변수 = 공 종류)도 가능하다.
:::

## 요약과 다음 챕터
